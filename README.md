# Proyecto de sistema de sistema de salas para jugar al ajedrez
Realizado durante el curso 2026/2027 en la ULPGC para la asignatura de Ingeniería del Software II por Margarita Cruz Pérez.
# Competencias trabajadas
- Diseñar una arquitectura de sistemas con frontend, backend y contratos de comunicación.
- Diseñar un frontend con tablero de ajedrez, creación de salas e interacción básica.
- Diseñar un backend con API o comunicación bidireccional.
- Aplicar arquitectura hexagonal en backend: casos de uso, puertos de entrada, puertos de salida y adaptadores.
- Aplicar arquitectura hexagonal en frontend de forma ligera: interfaz, casos de uso de interacción, puerto de servicio y adaptador de comunicación.
- Modelar usuarios, partidas, movimientos y estados de partida.
- Registrar partidas de forma persistente.
- Poner en contacto a usuarios mediante salas, invitaciones, emparejamiento o códigos de partida.
- Separar interfaz, comunicación, dominio, persistencia y configuración.
- Documentar ejecución local de frontend y backend.
